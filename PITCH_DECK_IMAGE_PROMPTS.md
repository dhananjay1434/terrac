# VERIDIAN CARBON — Full Image-Generation Prompt Pack (S1–S10)

**How to use (read once):**
1. Copy one slide's entire fenced block into the image AI. Add your tool's aspect flag (`--ar 16:9` in Midjourney; set 1920×1080 elsewhere).
2. **Text garble rule:** if ANY generated character is wrong, regenerate that slide as scaffolding — replace its text/content section with `completely blank panel(s), no text` — then typeset the text in Canva/Figma using the exact specs written in the block (they are written for humans too, on purpose). Fonts: Archivo Black / Bold (headlines), Lora Italic (serif pull-quotes), Inter (body), IBM Plex Mono (every number).
3. **Real-photo replacement:** wherever a block describes people or field scenes you already have real photos of, generate the "empty plate" variant noted under the block and composite your real photograph — real founders and real farmers always beat generated ones, and it's honest.
4. One generation per asset, one typesetting pass, done. Do not iterate on the model — iterate in Figma.
